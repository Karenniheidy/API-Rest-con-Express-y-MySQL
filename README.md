# API REST con Express y MySQL - Gestión de inventario

Aplicación backend desarrollada como parte de la formación en **Análisis y Desarrollo de Software (ADSO)** del SENA. Consiste en una API REST construida con **Node.js** y **Express**, interconectada con una base de datos relacional **MySQL** para la administración eficiente de un inventario de productos.

---

## Características principales
* **Arquitectura RESTful:** Endpoints claros y normalizados para consultas y registros.
* **Seguridad en base de datos:** Uso de consultas SQL parametrizadas para prevenir inyecciones SQL (*SQL Injection*).
* **Manejo de CORS:** Habilitado para la integración fluida con clientes frontend.
* **Validación de datos:** Control riguroso de solicitudes y tipos de datos con códigos de estado HTTP estándar.

---

## Tecnologías y dependencias
* [Node.js](https://nodejs.org/) - Entorno de ejecución de JavaScript.
* [Express](https://expressjs.com/) - Framework web minimalista.
* [MySQL2](https://www.npmjs.com/package/mysql2) - Conector optimizado para bases de datos relacionales.
* [CORS](https://www.npmjs.com/package/cors) - Middleware de recursos cruzados.
* [Nodemon](https://nodemon.io/) - Utilidad de desarrollo para recarga automática.
